                                                                 *overlook-peek*
Writing a custom peek source

A "peek source" is just a function. It gathers some context (the cursor, a
mark, an LSP result, ...), builds an |OverlookPopupOptions| table, and hands
it to `require("overlook.window").open_popup(opts)`. It opens nothing (and
usually notifies) when there is nothing to peek. There is no registration
step and no central adapter table: you bind the function to a key like any
built-in.

The built-in sources under `overlook.peek.*` (cursor, marks, definition) are
the canonical examples. A minimal synchronous source:
>lua
  local function peek_alternate_file()
    local alt = vim.fn.bufnr("#") -- the alternate buffer
    if alt == -1 then
      vim.notify("Overlook: no alternate buffer", vim.log.levels.WARN)
      return -- open nothing when there's nothing to peek
    end
    require("overlook.window").open_popup({
      target_bufnr = alt,
      lnum = 1,
      col = 1,
      title = vim.fn.bufname(alt),
    })
  end

  vim.keymap.set("n", "<leader>pa", peek_alternate_file, { desc = "Peek alternate file" })
<
Asynchronous sources (e.g. `vim.lsp.buf.*`) call open_popup later from their
own callback; see `overlook.peek.definition` for an async example.

When you already have an LSP location or a quickfix entry (for example the
`items` passed to `vim.lsp.buf.definition({ on_list = ... })`), you do not
have to build |OverlookPopupOptions| yourself. Pass the item to
|overlook-api.peek|:
>lua
  require("overlook.api").peek({
    filename = "lua/overlook/init.lua",
    lnum = 1,
    col = 1,
  })
<

LSP location lists share `overlook.peek.location`. One item opens a popup
immediately. Several items follow |OverlookOnMultiple|. Definition uses the
helper; a references or implementation source can call it from `on_list`:
>lua
  vim.lsp.buf.references(nil, {
    on_list = function(result)
      require("overlook.peek.location").open(result.items, {
        empty_message = "Overlook: No references found.",
        prompt = "Overlook: Select reference",
      })
    end,
  })
<
------------------------------------------------------------------------------
Class ~
{OverlookPopupOptions}
Fields ~
{target_bufnr} `(integer)` The buffer number to display in the popup.
{lnum} `(integer)` The line number (1-based) to position the popup at.
{col} `(integer)` The column (1-based) to position the popup at.
{title} `(optional)` `(string)` Optional title for the popup.

------------------------------------------------------------------------------
One location accepted by |overlook-api.peek|.

Identify the buffer with a document URI, a filename, or a buffer number.
URI is tried first (`uri` / `targetUri`, including the same fields on
`user_data`, where |vim.lsp.util.locations_to_items()| stores the original
location), then a non-zero `bufnr`, then `filename`. Position is `lnum` /
`col` (1-based, quickfix) when `lnum` is set; otherwise an LSP range
(`range`, `targetSelectionRange`, or `targetRange`; 0-based).

*OverlookPeekItem*
Class ~
{OverlookPeekItem}
Fields ~
{uri} `(optional)` `(string)` Document URI (`file:///...`), resolved with |vim.uri_to_bufnr()|.
{targetUri} `(optional)` `(string)` Location-link target URI. Used when `uri` is absent.
{filename} `(optional)` `(string)` Filesystem path. Used when no URI resolves and `bufnr` is unset.
{bufnr} `(optional)` `(integer)` Buffer number. Used when it is > 0 and no URI resolves.
{lnum} `(optional)` `(integer)` 1-based line (quickfix). Preferred over `range` when set.
{col} `(optional)` `(integer)` 1-based column (quickfix). Defaults to 1.
{range} `(optional)` `(table)` LSP range. `start.line` and `start.character` are 0-based.
{targetSelectionRange} `(optional)` `(table)` Location-link selection range (0-based). Preferred over `targetRange`.
{targetRange} `(optional)` `(table)` Location-link range (0-based). Used when no selection range is set.
{user_data} `(optional)` `(table)` Original LSP location, as set by |vim.lsp.util.locations_to_items()|.
{title} `(optional)` `(string)` Popup title. Defaults to the buffer's path.
